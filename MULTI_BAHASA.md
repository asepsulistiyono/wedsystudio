# 🌐 Panduan Lengkap Multi-Bahasa (Indonesia & English)

## 📋 Deskripsi

Aplikasi undangan pernikahan sekarang mendukung **multi-bahasa lengkap** dengan terjemahan komprehensif untuk **Bahasa Indonesia** dan **English**. Semua teks di halaman undangan telah diterjemahkan dengan baik.

## 🎯 Fitur Multi-Bahasa

### Bahasa yang Didukung:
- 🇮🇩 **Bahasa Indonesia** (Default)
- 🇬🇧 **English** (Full Translation)

### Cara Mengganti Bahasa:
1. Login sebagai Admin atau Super Admin
2. Buka tab **"⚙️ Bahasa & Agama"**
3. Pilih bahasa yang diinginkan:
   - 🇮🇩 Bahasa Indonesia
   - 🇬🇧 English
4. Klik **"Simpan Pengaturan"**
5. Halaman undangan akan otomatis berubah bahasa

## 🔧 Implementasi Teknis

### File Terjemahan:
```typescript
// src/utils/translations.ts
export const translations: Record<string, Record<string, string>> = {
  id: {
    // Semua terjemahan Bahasa Indonesia
  },
  en: {
    // Semua terjemahan English
  },
};

export function t(key: string, language: string): string {
  return translations[language]?.[key] || translations['id'][key] || key;
}
```

### Penggunaan di Komponen:
```typescript
// Contoh penggunaan di WeddingInvitation.tsx
const { weddingData } = useWedding();
const lang = weddingData.language;

// Menggunakan fungsi t() untuk terjemahan
<h2>{t('weddingEvent', lang)}</h2>
<p>{t('withBlessings', lang)}</p>
<button>{t('openInvitation', lang)}</button>
```

## 🚀 Fitur Tambahan

### Format Tanggal Otomatis:
- **Bahasa Indonesia**: "Sabtu, 15 Maret 2025"
- **English**: "Saturday, March 15, 2025"

- Tetap dalam format 24 jam untuk kedua bahasa
- Contoh: "08.00 WIB - Selesai"

- **Bahasa Indonesia**: "1.000.000" (titik sebagai pemisah ribuan)

## 💡 Tips Penggunaan

### Untuk Admin:
1. **Pilih bahasa sesuai target tamu**
   - Tamu lokal → Bahasa Indonesia
   - Tamu internasional → English

2. **Pilih format agama sesuai keyakinan**
   - Sesuaikan dengan agama mempelai
   - Atau gunakan "Universal" untuk netral

3. **Preview sebelum publish**
   - Selalu cek preview di tab "Bahasa & Agama"
   - Pastikan semua terjemahan sesuai

### Untuk Developer:
1. **Menambah terjemahan baru**
   - Edit file `src/utils/translations.ts`
   - Tambahkan key baru di kedua bahasa
   - Gunakan fungsi `t(key, lang)` di komponen

2. **Menambah bahasa baru**
   - Tambahkan object baru di `translations`
   - Contoh: `fr: { ... }` untuk French
   - Update fungsi `t()` jika perlu

3. **Menambah format agama baru**
   - Edit `religiousTemplates` di `translations.ts`
   - Tambahkan object baru dengan `id` dan `en`
   - Update dropdown di Super Admin

## 📞 Support

Jika ada terjemahan yang kurang tepat atau ingin menambah bahasa baru:
1. Edit file `src/utils/translations.ts`
2. Tambahkan/ubah terjemahan
3. Build ulang project
4. Test di halaman undangan

## 🎓 Best Practices

1. **Konsistensi Terjemahan**
   - Gunakan istilah yang sama di seluruh aplikasi
   - Contoh: "Mempelai" selalu "The Couple"

2. **Kultur yang Tepat**
   - Perhatikan budaya lokal
   - Contoh: "Insya Allah" tetap dalam English

3. **Format yang Sesuai**
   - Tanggal sesuai format lokal
   - Waktu dalam format yang familiar

4. **Testing**
   - Test kedua bahasa sebelum publish
   - Cek semua section
   - Pastikan tidak ada teks yang terlewat

## 📝 Catatan Penting

- Semua terjemahan disimpan di localStorage
- Perubahan bahasa bersifat instan
- Tidak perlu reload halaman
- Format agama dan bahasa independen
- Bisa kombinasi: Indonesia + Kristen, English + Islam, dll
